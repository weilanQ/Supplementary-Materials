The registry construction began with 172 pairs and 344 statements from 60 original trials. The older analysis validated both source pointers for each pair member. The denominator repair changed two development and twelve retrospective test inputs. Four test statements also changed wording. The IDs, partition and intended labels were retained. The per-input ledger is in `source_evidence/denominator_changes.json`; the full source checks are in `source_checks.jsonl`.

On headed tables, the original decision maker matched a generated claim record against rows parsed from the source. The main confirmation freeze is `main_freeze.json`. The later numeric boundary changes and additional condition test have separate manifests in `numeric_check/` and `condition_extension/`. The earlier series, adequacy of decompositions and limitations of the support-only adaptation are documented in `frozen_diagnostics.md` and `adapters/`. In the archived Llama MedScore adapter a heading was counted as a fact on 213 registry and 148 public statements. Removing the heading alone cannot restore omitted facts. `adapters/adapter_decisions.jsonl` preserves per-statement adapter results. `adapters/medscore_support.csv` and `.jsonl` report support and unscored results separately from contradiction. Source records, version-specific manifests and the statement IDs affected by eligibility and wording can be traced through `source_evidence/` and `../results/label_ledger.jsonl`.

The new Select protocol was frozen prior to the 40 development and 160 retrospective diagnostic calls. `../freeze.json` records that freeze. The strict ambiguity-priority variation and the check for later quotation errors were added only after the original reports. They replay identical replies without changing the original implementation. `../paired_audit.py` and `../results/paired_audit.json` record both checks. The fallback comparisons always use the same Direct prediction for each input. Reproduction requires the files contained in this archive; it exports the same labels for every original evaluation row used in the main comparison.

After the post hoc diagnosis, a separate 20-trial cohort was frozen before model inference. `independent/freeze.json` gives the input, model-code and scoring hashes. The independent report uses all 80 statements and reports the effect relative to a fresh one-pass Direct judgment on that cohort.
