When Numbers Agree but Relations Do Not

Can checking the source row correct a model’s verdict about a clinical trial result? The tables below show when a check changed a verdict. The examples let you follow that verdict back to the row and the model’s reply.

Two examples from the independent trials

Qwen chose the right row and read the denominator

The clinical benefit result was 1 participant out of 6. Qwen selected row 2, the reference row, but returned “Participants: 6” as the value quotation. The check therefore marked a correct statement as a mismatch.

NCT03490760 · Statement and source excerpt · Original Select reply

Llama returned the right verdict from the wrong row

The statement names a combination therapy. Llama selected row 3 for a single-agent arm. Row 12 was the compatible row. The verdict still agreed with the label on this statement and on its paired mismatch.

NCT05070247 · Statement and source excerpt · Original Select reply · Paired mismatch

Reproduce the tables

Extract the ZIP. In a terminal in the top-level folder containing README.md, run the command below with Python 3.10 or later. It rebuilds the results from the archived model replies on a CPU.

python reproduce.py
